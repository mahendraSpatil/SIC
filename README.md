# Simple Interest Calculator

A simple Bash script project designed to calculate simple interest based on user inputs.

## Description
This project takes the following inputs:
- **Principal Amount**
- **Annual Rate of Interest**
- **Time Period (in years)**

It then calculates and outputs the simple interest using the standard formula:
`Simple Interest = (Principal * Rate * Time) / 100`

## Usage
Run the script in a Linux/Unix terminal:
```bash
bash simple-interest.sh
